# 🏠 Home Service Marketplace Platform

Affordable & Trusted Home Services at Your Doorstep

---

## 📌 Project Overview

The **Home Service Marketplace Platform** is an on-demand service application that connects customers with verified skilled technicians such as:

* Plumbers
* Electricians
* AC Repair Professionals
* Carpenters
* Cleaning Staff

The platform enables customers to easily book home services while providing technicians with a reliable marketplace to manage jobs and earnings.

---

## 🎯 Objectives

* Provide affordable home services
* Enable quick technician booking
* Ensure trusted professionals
* Offer transparent pricing
* Improve convenience for households

# 🔄 Booking Workflow

1. User selects a service
2. Booking request is created
3. System finds nearby technician
4. Technician accepts request
5. User tracks technician
6. Service is completed
7. Payment is processed
8. User submits review

# ⚙️ Installation Guide

## Clone the Repository

```bash
git clone https://github.com/your-username/home-service-platform.git
```

## Navigate to Project Folder

```bash
cd home-service-platform
```

## Install Backend Dependencies

```bash
cd backend
npm install
```

## Run Backend Server

```bash
npm start
```

## Install Frontend Dependencies

```bash
cd ../frontend
npm install
```

## Start Frontend Application

```bash
npm start
```
